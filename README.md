## YouTube Summary Chrome Extension ( tube-digest )

> A lightweight and fast Chrome extension that extracts YouTube video transcripts and instantly summarizes the core content using the OpenRouter AI API.
---

## Key Features

* One-Click YouTube Summarization: Automatically extract transcripts and generate AI summaries directly from any YouTube watch page.
* Free & Flexible AI Models: Leverage OpenRouter to use completely free models (openrouter/free) or your preferred AI models without requiring credit card registration.
* Manifest V3 Compliant: Built using the latest Chrome Extension standards, minimizing background resource consumption.
* Secure API Key Management: Safely stores your personal API key using Chrome's local storage (chrome.storage.local).

## Tech Stack

* Frontend / Extension: JavaScript (ES6+), HTML5, CSS3, Chrome Extensions API (Manifest V3)
* AI API Integration: OpenRouter API (fetch, JSON Payload)
