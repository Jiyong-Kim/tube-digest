YouTube · OpenRouter

Tube Digest

시청 중인 영상의 자막을 읽어, 3줄 요약과 키워드, 타임스탬프별 핵심을 만듭니다.

API 키

OpenRouter API 키를 발급해 붙여 넣으세요. 모델은 openrouter/free 로 고정되어 있습니다.

사용 방법

  1. 자막이 있는 유튜브 영상을 엽니다.
  2. 제목과 설명 아래의 AI 요약 카드에서 요약하기를 누릅니다.
  3. 타임스탬프를 누르면 그 시점으로 이동합니다.

저장 위치

API 키는 이 브라우저의 확장 프로그램 저장소(chrome.storage.local)에만 둡니다. 다른 기기로 동기화하지 않습니다. 요약하기를 눌렀을 때만 자막 텍스트가 OpenRouter로 전송됩니다.
